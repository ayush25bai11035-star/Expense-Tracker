# Project Statement

## Expense & Budget Management System

The Expense & Budget Management System is a Java-based console application developed as a college project to manage personal expenses and monthly budgets.

The main objective of this project is to provide a simple way for a user to record expenses, view their spending, set a monthly budget and generate basic spending reports.

The system automatically generates an ID for every expense. Users can select an expense category from predefined options instead of entering category names manually. The application also provides category-wise spending and monthly summaries based on the date entered by the user.

The project is completely console-based and uses Java's standard libraries. It does not use any database, file handling or external libraries. The data is stored temporarily in an ArrayList while the program is running.

The project is divided into six classes: Expense, Category, ExpenseManager, BudgetManager, ReportManager and Main. Each class has a separate responsibility, which helps demonstrate the basic principles of object-oriented programming.

Through this project, I learned how to use classes and objects, encapsulation, constructors, ArrayList, methods, loops, switch statements, exception handling and Java date handling in a practical application.

The project is designed to be simple and easy to use while demonstrating the important Java and OOP concepts covered in the course.
